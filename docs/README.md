# Documentação do Projeto

Esta pasta centraliza a documentação relevante do repositório.

## Estrutura

- `docs/prd/` - Product Requirements Documents e objetivos do produto.
- `docs/architecture/` - diagramas, decisões arquiteturais e especificações de arquitetura.
- `docs/tdd/` - artefatos de Test Driven Development, cenários de teste e critérios de aceitação.
- `docs/rfc/` - Request for Comments, propostas de mudanças e discussões de design.

## Nomenclatura padrão

- Use `kebab-case` para nomes de arquivos: `feature-name.md`.
- Prefixe com tipo e data para documentos formais: `prd/2026-08-05-product-name.md`, `rfc/2026-08-05-api-design.md`.
- Para decisões e artefatos menores, use nomes descritivos curtos: `architecture/auth-flow.md`, `tdd/login-acceptance.md`.

Use subpastas e nomes claros para manter a documentação organizada e acessível.
