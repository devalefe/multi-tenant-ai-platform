# Documentação do Projeto

Esta pasta centraliza a documentação relevante do repositório.

## Estrutura

- `docs/prd/` - Product Requirements Documents.
- `docs/tdd/` - Technical Design Document.

## Nomenclatura padrão

- Use `kebab-case` para nomes de arquivos e prefixe com tipo e data para documentos formais: `prd/2026-08-05-product-setup.md`.

Use subpastas e nomes claros para manter a documentação organizada e acessível.
